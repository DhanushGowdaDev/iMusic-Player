## 🎶 Browse Categories

Explore music across different categories:

- **Bollywood** - Latest and popular Hindi songs
- **Arijit Singh** - Popular romantic tracks
- **A.R. Rahman** - Music from the legendary composer
- **Romantic** - Love and romantic songs
- **Punjabi** - Energetic Punjabi tracks
- **Classical** - Traditional and classical music
- **Sufi** - Sufi and spiritual music
- **Devotional** - Bhajans and devotional songs
- **Retro** - Classic Hindi songs

## 🚀 Getting Started

### Prerequisites

- Any modern web browser
- Internet connection

### Usage

- **Home**: Explore playlists and suggestions
- **Browse**: Search for songs and artists
- **Radio**: Play songs continuously
- **Library**: Access favorites and recently played songs
- **Queue**: Manage upcoming tracks

## 🔌 API

Saaz Music uses the **iTunes Search API** to search and retrieve music information.

The API provides:

- Song and artist information
- Album artwork
- Album details
- Short audio previews

> **Note:** Saaz Music uses the previews provided by the iTunes API and does not host full-length music tracks.
